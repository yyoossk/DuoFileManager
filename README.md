Duo FileManager 利用規約
制定日：2026年10月4日
本利用規約（以下「本規約」といいます）は、「Duo FileManager」（以下「本アプリ」といいます）の利用条件を定めるものです。本アプリを利用した時点で、利用者は本規約に同意したものとみなします。
第1条　本アプリについて
本アプリは、端末内のファイル・フォルダの閲覧、コピー、移動、削除、名前変更、検索、圧縮・展開、各種ファイル管理、クラウド・FTP・LAN等への接続その他のファイル管理機能を提供します。
利用可能な機能は、端末、OS、アプリのバージョン、利用する外部サービス等によって異なる場合があります。
第2条　利用者の責任
利用者は、自己の責任において本アプリを利用するものとします。
特に、ファイルの削除、移動、上書き、名前変更等を行う場合、重要なデータについて事前にバックアップを作成してください。
利用者の操作、本アプリと端末・外部サービスとの相性、端末故障その他の事情によりデータが消失または破損した場合、運営者に故意または重大な過失がある場合を除き、運営者は責任を負いません。
第3条　禁止事項
利用者は、本アプリの利用にあたり、以下の行為を行ってはなりません。
1. 法令または公序良俗に反する行為
2. 第三者の権利を侵害する行為
3. 不正アクセスその他の不正な目的で本アプリを利用する行為
4. 他人のファイル、サーバー、クラウドサービス等へ権限なくアクセスする行為
5. 本アプリまたは関連サービスの正常な運営を妨害する行為
6. 本アプリを利用してマルウェアその他の有害なデータを配布する行為
7. その他、運営者が不適切と判断する行為
第4条　外部サービス
本アプリは、Google Drive、FTP、LANその他の第三者が提供するサービスまたは機能と連携する場合があります。
これらの外部サービスについては、それぞれの提供者が定める利用規約、プライバシーポリシーその他の条件が適用されます。
外部サービスの仕様変更、障害、サービス終了、認証方法の変更その他の事情により、本アプリの一部機能が利用できなくなる場合があります。
第5条　広告
広告付きバージョンでは、Google AdMobその他の広告サービスを利用して広告を表示する場合があります。
広告サービスによる情報の取り扱いについては、各広告事業者のプライバシーポリシーが適用されます。
広告の内容、広告先の商品・サービス等について、運営者は当該広告主による提供内容を保証するものではありません。
第6条　権限
本アプリは、ファイル管理その他の機能を提供するため、利用者が許可した範囲で端末のストレージ、ファイル、ネットワーク等へのアクセス権限を利用する場合があります。
必要な権限が許可されていない場合、一部機能が利用できないことがあります。
第7条　知的財産権
本アプリに関する著作権、商標権その他の知的財産権は、運営者または正当な権利者に帰属します。
第三者のソフトウェア、ライブラリ、素材等については、それぞれに適用されるライセンス条件に従います。
第8条　サービス内容の変更・停止
運営者は、必要に応じて、本アプリの機能追加、変更、削除、提供停止等を行うことがあります。
重大な影響がある変更については、可能な範囲でアプリ内その他適切な方法により案内します。
第9条　免責事項
運営者は、本アプリについて、完全性、正確性、安全性、特定目的への適合性、継続的な動作等を保証するものではありません。
運営者に故意または重大な過失がある場合を除き、本アプリの利用または利用不能によって利用者に生じた損害について、運営者は責任を負いません。
ただし、消費者契約法その他の法令により、本規約の免責または責任制限が認められない場合は、その範囲で当該法令が優先されます。
第10条　本規約の変更
運営者は、法令の変更、本アプリの機能変更その他必要がある場合、本規約を変更することがあります。
変更後の規約は、アプリ内、デベロッパーサイトその他適切な場所へ掲載した時点から適用します。
第11条　準拠法・管轄
本規約は日本法に準拠します。
本アプリに関して紛争が生じた場合は、法令に別段の定めがある場合を除き、運営者の所在地を管轄する日本国内の裁判所を第一審の合意管轄裁判所とします。
第12条　お問い合わせ
本アプリに関するお問い合わせは、Google Playのストア掲載情報またはデベロッパーサイトに記載された連絡先から行ってください。
