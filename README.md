# Duo FileManager 利用規約

制定日：2026年10月4日

本利用規約は「Duo FileManager」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用した時点で、本規約に同意したものとみなします。

## 1. 本アプリについて
本アプリは、ファイル・フォルダの閲覧、コピー、移動、削除、検索、圧縮・展開、クラウド、FTP、LAN等のファイル管理機能を提供します。

## 2. 利用者の責任
本アプリは利用者自身の責任でご利用ください。

ファイルの削除、移動、上書き等を行う場合は、重要なデータを事前にバックアップしてください。

## 3. 禁止事項
以下の行為を禁止します。

- 法令または公序良俗に反する行為
- 第三者の権利を侵害する行為
- 不正アクセス
- 権限のないファイル、サーバー、クラウド等へのアクセス
- 本アプリまたは関連サービスの運営を妨害する行為
- その他、開発者が不適切と判断する行為

## 4. 外部サービス
本アプリはGoogle Drive、FTP、LAN等の外部サービスと連携する場合があります。

外部サービスについては、それぞれの提供者が定める利用規約およびプライバシーポリシーが適用されます。

外部サービスの仕様変更、障害、終了等により、一部機能が利用できなくなる場合があります。

## 5. 広告
広告付きバージョンでは、Google AdMob等の広告サービスを利用する場合があります。

広告サービスによる情報の取り扱いについては、各サービス提供者のプライバシーポリシーが適用されます。

## 6. 権限
本アプリは機能提供のため、利用者が許可した範囲でストレージ、ファイル、ネットワーク等へのアクセス権限を使用する場合があります。

## 7. 知的財産権
本アプリに関する著作権その他の知的財産権は、開発者または正当な権利者に帰属します。

第三者のライブラリ等については、それぞれのライセンス条件が適用されます。

## 8. 免責事項
本アプリの完全性、正確性、安全性、継続的な動作等を保証するものではありません。

本アプリの利用によって生じたデータ消失その他の損害について、開発者に故意または重大な過失がある場合を除き、責任を負いません。

ただし、法令により免責が認められない場合は、その法令が優先されます。

## 9. 規約の変更
本規約は、本アプリの変更や法令改正等に応じて変更する場合があります。

本規約は日本法に準拠します。
